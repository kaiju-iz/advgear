# AdvancedGear - Netherite -> Infernal -> Astral -> Celestial -> Primordial -> Eternal

**Status: Milestone 1.** Full framework + the complete **Infernal** tier. Astral, Celestial, Primordial, Eternal,
bosses and the building utility tools come in later milestones (they plug into the same YAML + ability framework).

**Paper only** (uses Adventure components and Paper item-meta APIs). Target: Paper 26.3 beta, Java 25.

## What's in Milestone 1
- Item system: every custom item has a PersistentDataContainer id (never matched by name); data-driven from `items.yml`.
- Smithing table upgrades (Netherite item + Infernal Upgrade Template + Infernal Ingot -> Infernal item), generated from
  `upgrade-from` in `items.yml`. Enchantments, name, trim and durability ratio are carried over. Wrong combinations are
  rejected; custom items are blocked from vanilla smithing/crafting recipes (no Netherite-ingot crafting from an Infernal Ingot,
  no repair-crafting that would strip custom data).
- Infernal tier: helmet/chestplate/leggings/boots, sword/pickaxe/axe/shovel/hoe, shard, ingot, template.
- 3 original weapons: **Infernal Greatsword** (Magma Slam + Cleave), **Ember Dagger** (Flame Flurry + Backstab),
  **Magma Warhammer** (falling-hit Shockwave). Pickaxe has **Magma Touch** (smelts raw iron/gold/copper).
- Armor set: per-piece fire reduction, shorter burn time, full-set ignite-on-hit and a capped chance to ignite attackers.
- Loot: mob drops (Wither, Wither Skeleton, Piglin Brute, Blaze) and bastion/fortress chest loot; spawner mobs never drop.
- Admin: `/advancedgear give|template|reload|inspect|recipes|version` (permission `advancedgear.admin`).
- Config: `config.yml` (stats of abilities, PvP, worlds, FX), `items.yml`, `recipes.yml`, `loot.yml`.

## Survival path (default config)
Kill a Wither / Wither Skeletons / Piglin Brutes for **Infernal Shards** -> craft **Infernal Ingot** (3 shards + Netherite Ingot)
-> find an **Infernal Upgrade Template** in bastion treasure (35%) or fortress chests (6%) -> upgrade at a smithing table.
Weapons are crafted at a crafting table (see `recipes.yml`).

## Build
Requirements: JDK 25 and Maven. `mvn package` -> `target/AdvancedGear-0.1.0.jar`.
Or push this folder to GitHub: `.github/workflows/build.yml` builds the jar and publishes it with the resource pack on the
"Latest build" release. The pack SHA-1 is on the workflow run summary.

## Install
1. Put the jar in `plugins/` on a Paper 26.3 server, start once.
2. Host `advancedgear-pack.zip` (release asset) -> set `resource-pack.url` and `resource-pack.sha1` (40-char SHA-1) in
   `plugins/AdvancedGear/config.yml`, `resource-pack.enabled: true`, `/advancedgear reload`.
3. Test: `/advancedgear give <you> greatsword`, `/advancedgear template <you> infernal`.

## Resource pack
`resource-pack/` is generated by `tools/generate_art.py` (placeholder pixel art + armor worn textures, palettes for all five
tiers already defined). `pack.mcmeta` uses min_format 88 / max_format 999 - set it to your exact 26.3 format if the client warns.

## Known limitations / untested
- This code was written without compiling or running it against the 26.3 API. Expect to fix some API-name errors on first build.
- Smithing uses native `SmithingTransformRecipe` with exact-item template/ingot. If your server build doesn't accept custom
  templates in the template slot, a custom upgrade GUI would be the fallback (not included in Milestone 1).
- Balance numbers are first guesses. Tiers 2-5, bosses, bow/crossbow/trident/shield variants and the terrain-clearing /
  precision-excavation / construction tools are not built yet.
- Ability damage is dealt through normal damage events (so region-protection plugins can cancel it) and resets the victim's
  invulnerability frames so slam/cleave hits always register.
